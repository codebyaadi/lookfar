# lookfar

lookfar is an open-source, self-hosted security watcher. It checks outside-in signals for you, such as actively exploited vulnerabilities in the software you run and look-alike domains seen in Certificate Transparency logs, and delivers what matters by email digest, signed webhook and an MCP server.

**Status: early development.** Nothing is ready to use yet.
